# Project status

The live project status (what shipped, what is in flight, pending work and recent decisions) is kept in the maintainers' private operations repo, together with implementation plans, the prompt archive, lessons, runbooks and the Terraform.

Self-hosters and contributors do not need it. To run your own copy, follow [SELF_HOSTING.md](./SELF_HOSTING.md); for how the app is built, read [ARCHITECTURE.md](./ARCHITECTURE.md) and the decision records in [adr/](./adr/).

What changed and when is public in [CHANGELOG.md](../CHANGELOG.md).
