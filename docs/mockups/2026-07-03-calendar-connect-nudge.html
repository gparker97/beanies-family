how it behaves

When

Gated so it's never noise: shows only when the googleCalendarSync flag is on, no calendar is connected (connections.length === 0), and it hasn't been dismissed. Connecting or dismissing hides it for good.

Where

Below the calendar (month view), in the same footer zone as the "Past activities" toggle. Never above the grid — the calendar is the page hero and butts flush against the command bar by design.

Do

"Connect" deep-links to Settings ?open=calendar-sync (opens the Google Calendar drawer directly — works now that Calendar is official). The ✕ dismisses it per-device, remembered.

Reuse

Clone the useInstallNudge localStorage idiom into useCalendarNudge (same 'pending' | 'dismissed' shape) — no new persistence machinery. Copy routes through uiStrings.ts (en + beanie).

Look

Sky-Silk fill (calm, recedes) with a single Heritage-Orange action — one accent, quiet everywhere else. The icon chip pairs 📅 with a peeking 🫘: the brand's "your beans, in your calendar" idea, kept to one accessory.
