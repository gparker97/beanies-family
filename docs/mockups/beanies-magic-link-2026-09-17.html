Four surfaces for the magic link: the combined save step at the end of pod creation, the joiner's copy of it, the revised recovery-kit arrival, and the Settings card that can only ever mint a new one. Each surface is drawn at 1024px and at 390px, in light and dark. Use the theme button to switch; it starts on your system setting.

A Creation — the combined save step

An unclosable modal at the end of pod creation. Two artifacts, one screen, one confirm. The kit card keeps its existing shape (code in Crockford groups, Save as PDF, Share); the magic link sits under it as a peer, not a footnote.

Each artifact owns its own save actions, so a person can act on one, then the other, and the single button at the bottom is the only way out.

C Recovery-kit arrival — PIN first, reset second

Today a kit lands the person on a Set a New PIN form, which takes the PIN away from someone who still knows it. The kit now lands on ordinary PIN entry, with the reset kept below the fold of attention: plain text, no tile, no orange fill, no border.

The reset line renders only when the beanpod was opened with a recovery kit. A family passphrase arrival shows the left panel without it.

D Settings — Security & Recovery

The token is never stored, so this card can report a link but never show one again. It carries a status line and exactly one action, and the warning sits attached to that action rather than floating at the top of the card.

After generating, the card becomes the same magic-link block used everywhere else, so the person recognises what they are looking at.
