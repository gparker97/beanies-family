Calendar clash indicator — design exploration

Issue #34 · A calm, privacy-preserving heads-up when a family activity overlaps something on a connected calendar. Names the calendar, never the event. Clear without nagging — and yours to quiet, with nothing ever lost for good.

Tip: click the × on a chip, or the quiet mark, to feel the minimize ↔ restore

The mark itself is a small overlap motif — two rounded shapes sharing one moment — in Heritage Orange. It carries one meaning everywhere: two things at the same time. It never uses Alert Red, because a clash is information, not a failure. Two states do all the work:

1

Two states, one mark

Active = a new overlap you haven't looked at: prominent enough to catch the eye, with the calendar named and a one-tap dismiss. Quiet = you've acknowledged it: it shrinks to a small persistent mark so it's never gone — tap it to bring the detail back. Acknowledging is remembered for the whole family, and a changed overlap (you move the time, it now clashes with something new) quietly becomes active again.

Month grid — the tightest space

The activity drawer — where you decide

Opening an activity is where the overlap gets its controls. A compact callout names the calendar and offers “This is OK” (quiets it everywhere) or, for the rare true conflict, Reschedule. A subtle “What's this?” link carries the longer privacy explanation off to the help article, so the callout stays a glance, not a paragraph. Once quieted, it collapses to a single reassuring line with an Undo, so the decision is never a dead end.

6

What this needs to be real

The visuals above are mostly recombinations of what already ships (the mark, the Heritage-Orange tints, the chip pattern). The one genuinely new ingredient is memory:

NEW Acknowledged-overlap memory. A small family-shared set remembering “you okayed this one,” keyed by activity + occurrence + which calendar — plus a fingerprint of the overlap, so moving the activity onto a new clash re-raises it. Persists across reload and devices.
KEEP Minimize, don't delete. A clash is derived from live data; a permanent "clear" could hide a real conflict forever. Quieting + Undo keeps you safe while still getting it out of the way.
REUSE One component, future-proof. The same mark + chip + callout can later flag beanies-vs-beanies overlaps (two kids, one slot) — a separate, no-scope feature — so the visual language is learned once.
