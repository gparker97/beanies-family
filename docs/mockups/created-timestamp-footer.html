🕒 "Created" date + time — a standard footer on todo & activity drawers

Both view drawers already show who created an item. We make it a standard convention to also show when — the full date and time — as a single, subtle footer line at the bottom of the drawer. The activity drawer already has a "Created by" footer (we just add the timestamp); the todo drawer's "Created by" moves from a mid-form labelled field into the same shared footer, so both read identically. Muted, low-emphasis, theme-aligned — it informs without competing with the item's content.

The shared footer line:

after (both):     Created by Greg · 21 Apr 2026 at 8:30am
