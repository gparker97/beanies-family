v4 — what changed (for the plan)

#1 Tile: merged the two meta rows into one (category · status), thinner colour strip, owner avatar with a soft ring, bolder progress bar — same info, less clutter. #2 New-list: categories are pills (app convention), templates are distinct cards (emoji + name + description). #3 FAB: no new FAB — the existing global QuickAddFab owns bottom-right; the page adds a header "＋ New list" button. #4: a "New list" action joins the global QuickAddSheet (Everyday group). #5: start date removed; "Repeats?" is its own section (one-off / repeats → frequency); a due date appears only for one-off lists (recurring shows "resets weekly"). #6: category + owner moved to a prominent top meta band, with the due date as a bold gradient chip when set.
