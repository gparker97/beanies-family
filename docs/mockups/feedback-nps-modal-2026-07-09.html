Behaviour notes (for the build)
  • Adaptive prompt — one optional free-text; its label keys to the score band: 0–6 "What's letting you down? What would make it better?" · 7–8 "What's one thing you wish beanies could do?" · 9–10 "What do you love most? (and anything you wish it did?)"
  • NPS-only — no separate star rating; the 0–10 recommend score is the rating. Send button enables once a score is picked.
  • Cadence — the modal auto-opens on a 30-day cycle at a natural pause (Nook home on app load, never mid-task); re-asked 30 days after a prompt whether or not they responded; engagement-gated + hard-capped + opt-out; per-family synced state so "don't ask again" carries across devices. Never on the first session / during onboarding.
  • Dismiss = asked — closing via X / Esc / backdrop counts as prompted and resets the 30-day clock, so closing is a valid answer and we don't re-interrupt soon.
  • Entry points — permanent "Share feedback" in the sidebar footer (near Help/Discord/Settings) + the scheduled auto-modal.
  • Privacy — payload carries app version + platform only; never financial data. Contact fields are optional and clearly reply-only.
