What changed

Rail add A full-width ＋ Add a recipe button sits under the cookbook search — it opens the existing recipe form (photo, ingredients, steps), so you can build the cookbook without leaving the planner. The new recipe lands in the rail, ready to drag. This is the richer sibling of the tap-a-slot quick-add (which stays name-only).

Fill height The board now claims the leftover vertical space and the four slot rows share it equally, so each slot is a roomy, comfortable drop zone instead of a thin strip floating in whitespace. Empty slots read as generous "drop here" targets, and the rail's recipe list flexes to match — more recipes visible, less scrolling. No filler content, just breathing room where the space already was.

Capped rows The board grows to fill the space but stops at a sensible height, so a tall monitor never stretches the four rows into cartoonish bands — the small remainder just stays as bottom margin. On a laptop it fills fully and compresses gracefully back toward today's size.

Drop anywhere The full day + slot area is the drop target now — not just the card. See Tuesday dinner: it already holds a card, yet the whole cell lights up and accepts the drop (the "Drop to add ＋" zone). Today you can only drop on top of the existing card, which gets harder as cells grow — this makes the entire cell catch the drop.
