cookbook — course, tags & meal grouping

Tracker #87 — the approved design. Meals are the existing four (no brunch). Course is one of eight; tags are free-form and stored lowercase.

Two other control-row directions were explored and rejected: a sticky filter/sort bar (plainest, but read as a toolbar bolted onto a scrapbook) and a collapsed filter tray (quietest, but the worst possible choice for a feature nobody knows exists yet).

The control row — recipe-box dividers

The group axis becomes card-index tabs, the way a physical recipe box is divided. The selected tab joins the tray below it, so the page reads as one object rather than a toolbar stacked on a grid. Course filters and sort live inside the tray.
