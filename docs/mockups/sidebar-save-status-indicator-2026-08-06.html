Notion #60 · pre-plan mockup · 2026-08-06

A save-status you can glance at.

Today only owners see positive save status — it's locked inside the Family Data modal — and the only always-on signal is a negative banner that waits for three failures. This puts a quiet, all-roles save indicator in the sidebar, right in the security cluster that already shows your file name and encryption. It follows the CIG's security-UI rule: felt, not seen — a whisper at rest that only warms to Heritage Orange when a save is actually struggling. Never Alert Red for this routine state.

UI

Quiet status row ● approved

A single left-aligned row that matches the existing security-indicator rows exactly — same weight, same low opacity. It reads as part of the seatbelt cluster, not a new widget. This is the most on-brand fit for "security indicators should be felt, not seen."

Why this shape

  • It joins a cluster that already exists. The sidebar footer already carries the file name (CloudProviderBadge), encryption status, and version. The save row slots in as one more security indicator — no new widget, strong reuse.
  • Quiet by default, warm when it matters. At rest it sits at the same low opacity as its neighbours (seatbelt principle). Degraded is the one moment it speaks up — in Heritage Orange, never Alert Red, because it's a routine "still trying," not a disaster.
  • Everyone sees status; only owners act. The gap this fixes is that non-admins saw nothing positive. Now they do — while recovery stays owner-scoped, so members never hit a dead-end button.
  • No new auto-popup. It's passive chrome. Nothing pops; the amber dot is the loudest it gets until the existing 3-strike banner takes over. Respects one-popup-per-session.
