Two mockups: filtering that can't be mistaken for assigning

Both move the member filter out from under the add bar and reframe it as a view lens. Each screen below is live — pick a member and watch the list filter, while the assignee picker (the ringed 👤 on the add bar) stays the only thing that changes a task.

Option A · recommended

"Showing" lens in the toolbar

A labelled segmented track beside Sort. It reads as a switch, member colour lights up only when active, and every bean stays one tap away — best for the 2–6-person families beanies is built for.

Option B · alternative

Stacked-avatar filter dropdown

Reuses the filter idiom beanies already ships in the header — stacked avatars, "Everyone" default. The pill row disappears; filtering collapses to one compact trigger. Scales to a big family; costs one click.
