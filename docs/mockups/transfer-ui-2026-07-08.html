Design notes

  • Third pill, not a new screen. Transfer joins the existing Money Out / Money In toggle. Its active state is Deep Slate (neutral) rather than orange/green — a transfer isn't income or spending, it's your own money moving between accounts.
  • Transfer mode hides the category, and the goal / loan / activity link controls — none apply to a transfer. It's one-time only (recurring transfers come later).
  • Converted row appears only when the two accounts differ in currency: "you send X → they receive Y", with the rate spelled out. Same-currency transfers stay clean.
  • No-rate state uses Heritage Orange (routine block), disables save, and tells the user exactly how to fix it — per the CIG's "no Alert Red for routine signals" rule.
  • Credit-card payoff hint appears under the destination when it's a card/loan, reinforcing that paying it reduces what you owe.
  • Everything else — squircle radii, Outfit/Inter type, tinted inputs, the 44×44 icon box, the full-width gradient save — is the standard BeanieFormModal, unchanged.
