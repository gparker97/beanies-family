Lists

Swim bag · 3 left

arrows

Flanking the date row rather than sitting in the header, so the control is beside the thing it moves. The left arrow occupies the axis gutter, which is empty at this height anyway, so it costs nothing; only the right gutter is new width. Both are 46px, matching the other controls a child reaches for. The header keeps the period label and the Today chip, which name where you are rather than moving you.

tap a date

Opens the today view on that day. The day is already on screen, so the useful next step is depth, not repositioning — and the today view is a far better day renderer than the sheet this replaces. This is the gesture that currently re-anchors the week, which was never the intent.

tap a strip day

Brings that day into the columns. Tapping Thu 10 redraws the grid starting Thursday, and Sun–Wed collapse into the strip. This is the only re-anchoring gesture, and it is the one that was asked for: a day you cannot see becomes a day you can.

Why fewer columns buys vertical space

Measured against a realistic week — most days ordinary, one 06:30 start, one 20:30 finish. The time window is the union across every visible day, so the two outliers tax every other day on screen. This is a layout change that pays a legibility dividend without touching the scale at all.

The hour scales with the screen the other half

The column change alone does not fill a tall screen. The grid enters its ladder at a fixed 0.8px per minute and only ever steps down from there, so an hour is 48px whether the plot is 480px or 1440px — measured, identical block heights at every height. The fix is to choose the entry point from the plot height rather than from a constant.

the floor

The hour is floored at today's 48px, so nothing moves on any screen at or below 720px — including every device already tested and every existing test, which run at 480px. Only genuinely tall plots grow.

still quiet

It is chosen from the screen, never from the day. The old failure — "two events and one of them half a wall" — came from dividing the available height among the day's live minutes, so a quiet day inflated. Here, two different days on the same screen still get the same hour. A quiet day stays quiet; it is only legible.

The day is already on screen, so the useful next step is depth rather than repositioning. The back button names where it returns to, matching the jobs board's existing pattern.
