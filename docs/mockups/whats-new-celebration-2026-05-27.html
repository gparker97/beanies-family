1

Row = a gift card

A soft orange→terracotta wash, a hairline gradient ring, a ✨ gradient medallion, a "just shipped" pill, and two quiet twinkles. It clearly reads as delight, not a chore — but stays inside the row rhythm (inset, same height band, same pip on the right).

2

Spotlight vs minor

The gift card is for spotlight releases (the ones already set to auto-open). Routine "fixes & improvements" deploys use the dialed-back flat row (✨ gradient chip only) so the list never becomes a wall of gradient cards.

3

Detail = unwrap

A gradient hero with the celebrating beanies + sparkles; the white body emerges over it with a rounded top (the "unwrapping" feel). Brief notes show the message centred; big releases drop in feature cards with "try it" — same frame.

4

Brand touches

The Pod (slate · terracotta · orange · sky, never reordered) divides the message from greg's Caveat handwritten sign-off; "every bean counts" sits quietly above the footer. Heritage Orange only — never Alert Red.

5

Motion (gentle)

Sparkles twinkle, the medallion floats, the body unwraps on open. All subtle, all prefers-reduced-motion-aware in the build (via useReducedMotion) — celebratory, never busy.
